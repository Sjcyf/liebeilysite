# АИС «Комнатки» — работающий макет

Работающий макет (прототип) автоматизированной информационной системы управления гостиничным комплексом.
Практическое занятие № 5 «Разработка прототипа АИС», МДК.01.04. Все данные вымышленные.

Статический сайт (HTML + CSS + JavaScript), без сборки и сервера. Данные хранятся в `localStorage` браузера.

## Демо-учётные записи

| Роль | Логин | Пароль |
|---|---|---|
| Администратор рецепции | reception | Recept!2026 |
| Кассир | cashier | Kassa!2026 |
| Маркетолог | marketing | Market!2026 |
| Руководство | director | Direct!2026 |
| Администратор безопасности | security | Secur!2026 |

## Механизмы защиты в макете

1. Аутентификация (пароли — хэш SHA-256 с солью), без сеанса доступен только вход.
2. Блокировка учётной записи после 5 неудачных попыток (15 мин), разблокировка администратором безопасности.
3. Меню и функции по ролям (RBAC), прямой переход на чужой экран → 403 + запись в журнал.
4. Маскирование ПДн (паспорт `****1234`, телефон, e-mail, дата рождения); раскрытие только рецепции, с целью и на 30 с.
5. Проверка ввода: обязательные поля, календарь для дат, форматы паспорта/телефона, выпадающие списки, пересечение броней.
6. Подтверждение опасных действий; удаление — с вводом слова «УДАЛИТЬ».
7. Журнал событий с цепочкой хэшей и проверкой целостности (только для администратора безопасности).
8. Автоматическое завершение сеанса при бездействии (5 мин, предупреждение за 30 с).

Плюс: водяной знак сеанса, гриф «Конфиденциально» на отчётах с ПДн, CSP-заголовок, экранирование вывода.

Вкладка «О прототипе» (доступна и без входа: `#about`) содержит матрицу ролей, схему навигации, структуру БД и заполненный чек-лист безопасности.

## Публикация на GitHub Pages

1. Загрузите файлы `index.html`, `styles.css`, `app.js`, `.nojekyll` в корень репозитория (или в папку, например `/aiz`).
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Для своего домена: укажите его в Settings → Pages → Custom domain (GitHub создаст файл `CNAME`) и включите *Enforce HTTPS*.

Все пути относительные, поэтому макет работает и в подпапке сайта (`https://домен/komnatki/`).
